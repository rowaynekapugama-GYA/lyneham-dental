Written 19 November 2026 for v1.6.0, updated 23 November 2026 for v1.7.0. The docs folder is not deployed.

Rules for every photo:
- Licensed stock that GYA has bought, or a photo the practice took. Nothing downloaded from the web, and no AI-generated images.
- Landscape, at least 2000 px wide, realistic and clinically accurate.
- No branding or logos, and no before and after claims.

Each slot below currently shows a neutral, brand-tinted line illustration so the page doesn't look broken. To swap a photo in, save it as WebP at 1600 x 900 under the same file name, plus a 240 x 240 square crop as the `-thumb` file where one is listed. Or send the photo to GYA and we'll prepare both files.
